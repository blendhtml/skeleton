# Skeleton

## Usage

Clone the repository:

```bash
git clone https://github.com/blendhtml/skeleton.git my-project
cd my-project
```

Remove the existing Git history and initialize a fresh repository:

```bash
rm -rf .git
git init
```

Add your files:

```bash
git add .
```

Create the first commit:

```bash
git commit -m "Initial commit"
```

Add your own remote repository:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Push the project:

```bash
git branch -M main
git push -u origin main
```

The skeleton is now ready to be used as the base for your new project.
